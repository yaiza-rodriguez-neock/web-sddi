# SDDI — Social Data Driven Impact

Landing page de SDDI, el Espacio de Datos para el impacto social.

## Web publicada

[https://yaiza-rodriguez-neock.github.io/web-sddi/](https://yaiza-rodriguez-neock.github.io/web-sddi/)

## Desarrollo local

Abre `index.html` en un navegador. No requiere instalación de dependencias ni proceso de compilación.

## Estructura

- `index.html`: estructura y contenido de la web.
- `styles.css`: estilos, tipografías y reglas responsive.
- `script.js`: interacciones, FAQ y validaciones de formularios.
- `assets/`: imágenes, iconos y fuentes locales.
